Privacy Policy

DaFeiYu · effective 26 October 2026

Summary

DaFeiYu runs entirely on the operator's own computer. It has no server, no user account system, and no analytics. Nothing is collected about you by a third party, because there is no third party. The only outside service it contacts is TikTok.

What is stored, and where

DataWhere it livesWhy
TikTok access token and refresh token Local disk, encrypted with Windows DPAPI under the operator's Windows user account To call TikTok's API on the operator's behalf without asking them to log in again each time
App client key and client secret Local disk, encrypted the same way To complete the TikTok OAuth exchange
Video files An approved local folder on the operator's machine As the source for an upload. Files are read, sent to TikTok, and not copied elsewhere.
Non-secret settings (app client key, redirect URI, upload folder path) Local settings.json Basic configuration

What is not collected

No analytics, telemetry, crash reporting, advertising identifiers, device fingerprints, contacts, location, or browsing history. No usage data is sent anywhere. The tool does not read files outside the operator's approved upload folder.

What is sent to TikTok

Only what TikTok's own API requires:

  • the authorization code during login, exchanged for tokens at open.tiktokapis.com;
  • the selected video file, uploaded in chunks, to TikTok's upload host;
  • the video size and chunking parameters, and the publish_id when checking status.

No video is posted publicly by the tool. Uploads land in the operator's TikTok inbox as drafts, and the operator decides in the TikTok app whether anything becomes visible.

Data sharing

None. Credentials and video files are never sold, rented, or disclosed to any third party. There is no sub-processor and no cloud backend.

Retention and deletion

Tokens remain on the local machine until they expire, are refreshed, or are deleted. To remove all stored data:

  • revoke the app's access in TikTok under Settings → Security & permissions → Manage app permissions;
  • delete the contents of D:\TikTok-AI\secrets on the local machine.

Because no data is held anywhere but the operator's own computer, deleting it locally is a complete deletion.

Security

Secrets are encrypted at rest with Windows DPAPI, bound to the operator's Windows user account, so another Windows account on the same machine cannot read them. The OAuth flow uses PKCE and a random state value, and the redirect is caught on loopback only — no credential ever crosses a public server.

Children

The tool is not directed at children and is not distributed to the public.

Changes

If this policy changes, the effective date above is updated.
